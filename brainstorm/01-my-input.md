# Source 1: Initial Breakdown

## Universal Principles (Apply to ALL Subjects)

### 1. Active Processing
- Don't copy — reconstruct. Read a section, close the book, write from memory.
- Paraphrase in your own words. If you can't explain it simply, you don't understand it yet.
- The Feynman Technique: Write explanations as if teaching someone with no prior knowledge.

### 2. Retrieval Practice Built Into Notes
- Notes should contain questions, not just facts.
- Use the Cornell Method structure: cues/questions on one side, notes on the other, summary at the bottom.
- End each topic with a self-test section (cover answers, test yourself).

### 3. Spaced Review
- Review notes within 24 hours (forgetting curve is steepest in the first day).
- Flag sections by difficulty: ✓ (easy), ~ (needs review), ✗ (don't understand).
- Weekly consolidation session for all ✗ items.

### 4. Dual Coding
- Combine words + visuals for every major concept.
- Diagrams, flowcharts, mind maps, tables — visual memory is stronger and lasts longer.

### 5. Elaboration
- Ask "why?" and "how?" for every fact, not just "what?"
- Connect new concepts to what you already know.
- Cross-reference related topics within and across subjects.

### 6. Concrete Examples
- Abstract concepts stick when tied to specific, real-world examples.
- Always include at least one worked example or case study per concept.

## Subject-Specific Adaptations

### Mathematics & Physics (Procedural Knowledge)
- Core unit: Problem types and solution methods
- Best format:
  - Formula sheet (all formulas in one place)
  - Step-by-step solved examples (multiple methods if applicable)
  - Problem classification (when to use which method)
  - Common mistakes (sign errors, unit mistakes, skipped steps)
- Practice style: Do problems from scratch, not just read solutions
- Visual encoding: Graphs, geometric diagrams, free-body diagrams

### Biology & Chemistry (Declarative + Visual Knowledge)
- Core unit: Systems, processes, and classifications
- Best format:
  - Labeled diagrams (cells, organs, molecular structures)
  - Process flowcharts (photosynthesis, chemical reactions, cell division)
  - Comparison tables (plant vs animal cell, ionic vs covalent bonds)
  - Terminology glossary (prefixes, suffixes, root words)
- Practice style: Label diagrams from memory, explain processes step-by-step
- Visual encoding: Heavy — diagrams are essential, not optional

### History & Political Science (Narrative + Causal Knowledge)
- Core unit: Events, causes, effects, and significance
- Best format:
  - Timelines (chronological order with context)
  - Cause-effect chains (what led to what, and why it matters)
  - Comparison tables (revolutions, constitutions, political systems)
  - Key figures and their contributions
  - Primary source quotes (for essay writing)
- Practice style: Explain causes and consequences, compare/contrast events
- Visual encoding: Timelines, maps, flowcharts of events

### Geography (Spatial + Analytical Knowledge)
- Core unit: Locations, patterns, and human-environment interactions
- Best format:
  - Maps (physical, political, thematic)
  - Diagrams (rock cycle, water cycle, atmospheric layers)
  - Data tables (population, climate, resources)
  - Case studies (specific examples of concepts in action)
- Practice style: Map labeling, explain patterns, analyze data
- Visual encoding: Maps are essential, diagrams for processes

### Economics (Analytical + Applied Knowledge)
- Core unit: Concepts, models, and real-world applications
- Best format:
  - Definitions (precise, exam-ready)
  - Graphs and curves (supply/demand, production possibilities)
  - Real-world examples (current events, case studies)
  - Formulae and calculations (GDP, elasticity, multipliers)
- Practice style: Analyze scenarios, interpret graphs, apply concepts
- Visual encoding: Economic graphs, flowcharts of processes

### English & Hindi (Analytical + Linguistic Knowledge)
- Core unit: Texts, literary devices, grammar rules
- Best format:
  - Chapter/summary notes (prose and poetry)
  - Character analysis (traits, motivations, development)
  - Theme analysis (with textual evidence/quotes)
  - Literary devices (with examples from the text)
  - Grammar rules (with examples and practice)
  - Vocabulary (new words, meanings, usage)
- Practice style: Literary analysis, grammar exercises, writing practice
- Visual encoding: Mind maps for themes, tables for literary devices

### Computer Science (Procedural + Conceptual Knowledge)
- Core unit: Algorithms, syntax, and problem-solving
- Best format:
  - Code examples (with comments)
  - Algorithm steps (pseudocode or flowcharts)
  - Syntax reference (key commands, functions)
  - Common errors and debugging tips
  - Concept explanations (data structures, networking, etc.)
- Practice style: Write code from scratch, trace algorithms, debug
- Visual encoding: Flowcharts, diagrams of data structures, network topologies

## Workflow for Managing 8-9 Subjects

### 1. Consistent Template, Flexible Content
- Use the same skeleton across all subjects (definitions, explanations, questions, summary)
- Adapt the content sections based on subject type
- This reduces cognitive load — you always know where to find things

### 2. One Chapter at a Time
- Don't jump between subjects mid-chapter
- Complete notes for one chapter before moving to the next
- Batch similar subjects if possible (e.g., History + Pol Sci, Physics + Chemistry)

### 3. The 1-Page Revision Sheet
- After detailed notes, create a single-page summary with only:
  - Key formulas/definitions
  - Must-remember facts
  - Common exam traps
- This is what you review before exams, not the full notes

### 4. Interleaving Practice
- After mastering one chapter, mix practice questions from 2-3 recent chapters
- Prevents "illusion of competence" from repetitive practice
- Builds flexibility in applying knowledge

### 5. Notes + Questions Together
- Don't separate note-taking from practice
- Every concept should have at least one associated question
- Include the answer inline (for self-testing by covering)

## Common Pitfalls to Avoid

- Highlighting everything — highlighting ≠ learning, it feels productive but isn't
- Making notes "pretty" — neatness has diminishing returns, focus on usefulness
- Notes without questions — passive notes decay fast, retrieval practice is essential
- Ignoring textbook exercises — exam questions often mirror them
- Not reviewing within 24 hours — forgetting curve is steepest in the first day
- Copying the textbook verbatim — if you're not processing, you're not learning
- All detail, no summary — you need both the deep notes and the quick revision sheet
